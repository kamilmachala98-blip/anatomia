# Materiały techniczne i medyczne

- MDN Web Docs — dokumentacja DOM, formularzy i obsługi zdarzeń: https://developer.mozilla.org/en-US/docs/Web/API/Document
- Khronos — oficjalna specyfikacja glTF/GLB 2.0 (w tym nodes, meshes i accessors): https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html
- Gray — *Anatomia dla studentów* (przesłane tomy); Sobotta — *Atlas anatomii człowieka*; Rohen–Yokochi — *Fotograficzny atlas anatomii człowieka* — materiały źródłowe użytkownika do **przyszłej weryfikacji** topografii. Ich ryciny nie zostały skopiowane do paczki.

**Ważne**: dodane funkcje audytu nie oznaczają, że przeprowadzono pełne porównanie graficznej anatomii każdej ilustracji z wyżej wymienionymi podręcznikami.
