# Anatomia z Graya 4.64

Wersja rozwinięta z 4.54, zachowuje 96 ilustracji, 96 miniaturek, quizy, fiszki, rejestr oznaczeń i laboratorium demonstracyjnego modelu 3D.

## Nowości
- Lokalny warsztat audytu rycin i współrzędnych z notatkami źródłowymi;
- cofanie i ponawianie zmian punktów;
- bezpieczny import/eksport audytu JSON;
- przechodzenie między dostępnymi warstwami w niezmienionej projekcji;
- nawigacja po oznaczonych strukturach;
- filtrowanie punktów zgłoszonych do korekty;
- wskazywanie brakującej lokalizacji na innej rycinie **wyłącznie na żądanie**;
- czytelny status niezależnej geometrii 3D.

## Uruchomienie
- Wersja folderowa: otwórz `index.html` (przy wdrożeniu Netlify cały katalog musi być w katalogu głównym publikowanej strony).
- Wersja jednoplikiowa: `Anatomia_Gray_4_64_Samodzielna.html` (samodzielne zasoby, offline).

## Dokładność
Wszystkie dotychczasowe oznaczenia należy traktować jako **orientacyjne**. Nie zakończono medycznej walidacji żadnej pełnej ryciny. 3D jest poglądowe, nie segmentowane.

Zobacz `CYKLE_4_55-4_64.md` oraz `RAPORT_TESTOW_4_64.md`.
